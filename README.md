# 🌦️ Real-Time Weather Predictor

The **Real-Time Weather Predictor** is a modern, dark-themed weather web app built with **Streamlit**.  
It provides **real-time weather updates** and a **5-day forecast** using the **Open-Meteo API** — no API key required!  
You can search for a city or select a location on an **interactive map** to instantly view weather data in a glowing neon interface.

---

## 🚀 Features

- 🔍 **Search by City** – Quickly find weather details for any city worldwide.  
- 🗺️ **Interactive Map** – Click anywhere on the map to get weather info for that location.  
- 🌡️ **Real-Time Data** – See current temperature, wind speed, and weather conditions instantly.  
- 🎨 **Dark Neon UI** – Sleek black background with glowing sky-blue effects for a futuristic look.  
- 📅 **5-Day Forecast** – Get a glance at upcoming weather conditions with colorful forecast cards.  
- 🎈 **Animated Effects** – Enjoy dynamic visual effects like snow and balloons for specific weather types.

---

## 🧠 Tech Stack

- **Frontend/UI:** [Streamlit](https://streamlit.io)  
- **Mapping:** [Folium](https://python-visualization.github.io/folium/) & [streamlit-folium](https://github.com/randyzwitch/streamlit-folium)  
- **Weather API:** [Open-Meteo API](https://open-meteo.com/en/docs)  
- **Data Handling:** Pandas, Requests
